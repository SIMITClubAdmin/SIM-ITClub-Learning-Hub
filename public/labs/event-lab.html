Click

"click"

The doorbell. Fires when someone presses and releases on the element.

0
rings
let count = 0;
const bell = document.querySelector("#bell");
bell.addEventListener("click", function () {
  count++;
  rings.textContent = count;
});

TRY Ring it 10 times to unlock the star. Then press Reset.

Hover

"mouseover"

Automatic doors. Fires when the mouse moves onto the element; "mouseout" when it leaves.

Move your mouse onto the planet 
const planet = document.querySelector("#planet");
planet.addEventListener("mouseover", function () {
  planet.classList.add("hot");
});
planet.addEventListener("mouseout", function () {
  planet.classList.remove("hot");
});

TRY Hover onto the planet and off again, 3 times. On a phone, tap instead: touch screens have no hover.

Type

"input"

A live name tag printer. Fires on every single letter you type or delete.

HELLO, MY NAME IS … 0 / 24 letters 
nameBox.addEventListener("input", function () {
  tagName.textContent = nameBox.value;
  tagCount.textContent = nameBox.value.length + " / 24 letters";
});

TRY Type itcamp (any capitals). Watch how many events one word fires.

Keyboard

"keydown"

A game controller. Fires when a key goes down, and event.key says which one.

Submit a form

"submit"

Posting a letter. Fires when the form is sent; preventDefault() stops the page reloading so JS can check it first.

Nothing submitted yet.

form.addEventListener("submit", function (event) {
  event.preventDefault(); // stay on this page
  if (nameBox.value === "") {
    result.textContent = "Please enter your name";
    return;
  }
  result.textContent = "Welcome, " + nameBox.value + "!";
});

TRY First press the button with the form empty, then fill it in properly.

Choose

"change"

A light switch. Fires once when a choice is made, not on every letter like "input".

This card listens to the two controls above.
colour.addEventListener("change", function () {
  card.style.borderColor = colour.value;
});
glow.addEventListener("change", function () {
  card.classList.toggle("glow", glow.checked);
});
